## 🎯 Sobre o Projeto
Este repositório contém um notebook Jupyter desenvolvido em **Python** voltado para a aplicação de técnicas de **Análise de Dados e Estatística**. O objetivo principal é explorar o conjunto de dados, tratar inconsistências, aplicar testes estatísticos ou manipulações avançadas e extrair insights acionáveis por meio de visualizações claras.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
As seguintes bibliotecas e ferramentas foram utilizadas neste projeto:
* **Linguagem:** Python
* **Manipulação e Análise de Dados:** Pandas, NumPy
* **Visualização de Dados:** Matplotlib, Seaborn
* **Ambiente de Desenvolvimento:** Google Colab / Jupyter Notebook / VS Code

---

## 📈 Etapas da Análise
1. **Importação e Limpeza de Dados:** Carregamento do dataset, tratamento de valores nulos e padronização de tipos.
2. **Análise Exploratória de Dados (EDA):** Investigação de distribuições, correlações e métricas estatísticas descritivas (média, mediana, desvio padrão).
3. **Aplicação Estatística / Modelagem:** Execução de testes estatísticos ou transformações relevantes para responder aos objetivos do estudo.
4. **Visualização de Resultados:** Geração de gráficos informativos para facilitar a interpretação dos dados extraídos.
